How Argosight works

1. You ask
Pick a workflow, give an area (geometry) and a time range via the Python client or REST API.
→
2. Server plans
The REST server reads the workflow graph (tasks + edges) and queues ready tasks.
→
3. Workers run ops
Each task runs an operator in a Docker worker: download Sentinel/NAIP/weather, mask clouds, compute indices, run ML.
→
4. Results
Outputs (rasters, timeseries, geometries) are cached on disk and returned to the client.
